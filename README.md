# Blue Trajectory

A 2D retro platformer made for the Retro Platformer Jam 2026. Aim each jump in two timed steps: press Accept (Space or
Enter) to start the power meter, again to stop it and start the angle meter, and a third time to launch.

## Run and test

Open this folder in Godot 4.6 and press Play (main scene `res://stages/splash/studio_splash.tscn`), or:

```bash
godot --path .
```

There are no automated tests yet. Design, board, bugs and tools are in the studio knowledge base:
`../../studio/games/blue-trajectory/blue-trajectory.md`.
